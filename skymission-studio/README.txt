SkyMission Studio — Elementor Section Editor + WooCommerce
===========================================================

This version keeps the original SkyMission design/CSS/JS but converts the homepage into SIX independent Elementor custom widgets:
1. Hero
2. How It Works
3. Services
4. Why Choose
5. FAQ
6. CTA

Each widget is a real Elementor element with separate controls for headings, paragraphs, buttons, links, images, and FAQ text. Therefore changing a paragraph/title does not require editing one giant HTML block.

Header/Footer:
- PHP fallback remains in place.
- Elementor Pro Theme Builder locations are registered.
- With Elementor Pro, create a Header and Footer template and set Display Conditions to Entire Site. They will appear on every page.

WooCommerce:
- Theme support enabled.
- Standard WooCommerce wrappers are included.

Install:
1. Upload and activate the ZIP.
2. Install/activate Elementor.
3. Install/activate WooCommerce.
4. For Elementor Header/Footer Theme Builder, install Elementor Pro.
5. Open Pages > SkyMission Home > Edit with Elementor.
6. You will see six separate SkyMission widgets. Select any widget and edit its individual text/image/link controls.

Important:
The original one-page HTML is retained as original-content-reference.html. The live homepage no longer uses one giant HTML widget.
